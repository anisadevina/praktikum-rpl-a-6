# Retrospektif 
## What went well? (Apa yang berjalan baik)
- Seluruh fitur must-have berhasil diimplementasikan dan berfungsi sesuai acceptance criteria yang telah ditetapkan
- Fitur should-have juga berhasil diimplementasikan seluruhnya, melebihi target MVP yang ditetapkan di awal
- Keseluruhan program berhasil diselesaikan tepat waktu sesuai jadwal praktikum
- Kolaborasi tim berjalan dengan baik meskipun ini pertama kalinya mengerjakan proyek perangkat lunak secara penuh dari awal hingga rilis
- Penggunaan Git dan GitHub untuk kolaborasi berhasil diterapkan dengan konsisten, termasuk penanganan merge conflict yang diselesaikan secara bertahap
- Pembagian peran antara frontend website - android dan backend website - android berjalan cukup jelas sehingga masing-masing anggota dapat fokus pada bagian masing-masing
- Seluruh 20 test case pengujian manual menghasilkan status Pass tanpa ditemukan bug kritis 
- Test case menggunakan konsep AAA menghasilkan status Pass dan berhasil menemukan bug di dalamnya.

## What didn't go well? (Apa yang tidak berjalan baik) 
- Detail kebutuhan fitur baru sering muncul setelah sistem sudah berjalan, bukan pada fase perancangan, sehingga memerlukan penyesuaian yang tidak terencana
- Setup environment di awal pengembangan memakan waktu cukup lama, mulai dari konfigurasi Laragon, koneksi database, hingga aplikasi web dapat berjalan
- Inkonsistensi tampilan UI masih ditemukan menjelang akhir pengerjaan, padahal idealnya sudah diselesaikan lebih awal di fase implementasi
- Sinkronisasi kontrak API antara sisi frontend dan backend tidak selalu berjalan mulus, beberapa endpoint perlu disesuaikan saat integrasi.
- Terdapat fitur could have yang belum berhasil diterapkan

## What can we improve? (Apa yang bisa diperbaiki ke depan) 
- Mendefinisikan spesifikasi fitur dan kontrak API secara lebih detail di fase perancangan sebelum mulai coding, agar tidak banyak penyesuaian di tengah jalan
- Menetapkan panduan UI yang lebih ketat sejak awal dan melakukan review tampilan secara berkala, bukan hanya di akhir
- Membangun fondasi teknis seperti environment dan struktur folder lebih awal agar waktu pengembangan fitur tidak terpotong untuk urusan setup
- Meningkatkan pemahaman teknis secara proaktif sebelum semester dimulai, khususnya untuk teknologi yang akan digunakan dalam proyek
- Melengkapi fitur-fitur yang belum sempat diimplementasikan seperti fitur Could-have pada backlog, agar aplikasi memberikan nilai yang lebih lengkap bagi pengguna
- Melakukan perbaikan dan penyeragaman tampilan UI secara menyeluruh agar pengalaman pengguna lebih konsisten dan profesional di semua halaman

## Shout-outs (Apresiasi untuk anggota tim) 
- Apresiasi untuk seluruh anggota tim yang tetap berkomitmen menyelesaikan proyek meskipun ini adalah pengalaman pertama membangun Platform lengkap dari nol
- Apresiasi telah meluangkan waktu untuk kerja kelompok di akhir minggu
- Apresiasi telah menghabiskan dana pribadi untuk membeli kopi dan makanan
